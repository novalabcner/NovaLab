# NovaLab

NovaLab is a student-led science collective website built with Vite, React, TypeScript, TanStack Router, and Tailwind CSS.

## Development

You need Node.js and npm.

```sh
npm install
npm run dev
```

For a production build:

```sh
npm run typecheck
npm run build
npm run preview
```

## Built with

- Vite
- TypeScript
- React
- TanStack Router
- Tailwind CSS
