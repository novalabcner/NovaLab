# Ghid simplu de administrare

- Editează textele paginilor direct în documentele Google Docs și în foaia Pages.
- Pentru articole, setează metadata în Articles. Textul canonic în română este în documentul Google Docs indicat de `ro_document_id`.
- Pentru evenimente, completează foaia Events. Documentul este doar referință editorială.
- Pentru echipă și proiecte, editează rândurile din Sheets și imaginile din Media.
- Nu edita formularele raw sau Sheetsurile interne pentru publicare.
- Publicare: `published=TRUE`.
- Traducere: publică EN doar după `english_reviewed=TRUE`.
